# 📝 To-Do List App

A simple and interactive To-Do List application built with HTML, CSS, and JavaScript. It allows users to manage their daily tasks by adding new tasks, marking them as completed, and deleting tasks.

## ✨ Features

* Add new tasks.
* Mark tasks as completed.
* Delete tasks.
* Save tasks using Local Storage.
* Keep tasks saved after refreshing the page.
* Simple and user-friendly interface.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage

## 📸 How to Use

1. Enter a task in the input field.
2. Click the **Add** button to add the task.
3. Click on a task to mark it as completed.
4. Click the delete icon to remove a task.
5. Your tasks are saved in the browser using Local Storage.

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/BadeaQlalawa/to-do-list.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
